# 🎓 MyUniLife – Role-Based Event Management Platform

MyUniLife is a modern web-based platform designed for colleges and universities to manage events, track student participation, and connect students, clubs, and alumni through a unified system.

---

## 🚀 Live Overview

MyUniLife provides a **role-based ecosystem** where each user interacts with the platform differently:

- 🎓 Students → Discover & participate in events  
- 🏫 Clubs → Create & manage events  
- 👨‍🎓 Alumni (Guests) → Analyze engagement & host events  
- 🛠 Admin (Planned) → Control and monitor the system  

---
